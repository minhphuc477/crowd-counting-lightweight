# Find Skills

The Find Skills meta-skill enables discovery and installation of capabilities from the open agent skills ecosystem.

## Core Directives

1. **Search**: Use `npx skills find <query>` to search for skills interactively or by keyword.
2. **Install**: Use `npx skills add <owner/repo@skill> -g -y` to install a skill automatically.
3. **Verify**: Check install count (>1K preferred) and author reputation before adopting external skills.
4. **Update**: Use `npx skills check` and `npx skills update` to keep installed skills current.

## Common Categories
- **AI/ML Research**: training, fine-tuning, interpretability, evaluation, tokenization.
- **Web & Fullstack**: react, nextjs, typescript, tailwind, fastapi.
- **DevOps & Infrastructure**: docker, kubernetes, modal, ray, deepspeed.
- **Data Engineering**: polars, duckdb, datasets, parquet, dask.
